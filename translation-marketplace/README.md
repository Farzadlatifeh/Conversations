# Translation Workspace Plugin Marketplace

This directory contains a skill-only ChatGPT/Codex plugin named **Translation**.

Workspace import settings:
- Source: https://github.com/Farzadlatifeh/Conversations
- Path: translation-marketplace
- Branch: translation-plugin

After import, open Workspace settings > Plugins > Translation and set its installation policy to **Installed** for the intended roles. No external app or MCP connection is required.
